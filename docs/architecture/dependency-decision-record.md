### Licensing and version verification status

This decision record is not a complete dependency inventory or license audit. Frontend declared dependencies and resolved versions are recorded in `frontend/package.json` and `frontend/package-lock.json`. The exact vendored C++ header revisions and all transitive dependency license obligations were not established in this audit. No `docs/reference/THIRD_PARTY_LICENSES.md` file was found. Verify the actual redistributed dependencies and include their required notices before submission; do not infer license compliance from this design record.
